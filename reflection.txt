One of the things I learned was how branches could be used to complete different work without interfering with the rest of the project. Git can also detect conflicts where different parts of a file have been changed in different ways on different branches. At first it seemed like a complicated process but resolving a merge conflict in VS Code helped to clear up the process. Another surprise was that GitHub’s pull requests are used to complete reviews of work to be incorporated into a project, allowing discussion about the changes before they are merged into the project. The lab as a whole helped me see how Git and GitHub can organize, track and complete software development.
